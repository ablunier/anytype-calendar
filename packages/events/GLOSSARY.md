# Events

The user's Anytype objects placed on the calendar by their dates, and the edits made to them from it.

## Language

**Dated object**:
An Anytype object the calendar draws as an Event, placed by the From and To dates of the type or query that puts it there. It is one Event however many of those bring it; one with only a From date is still a Dated object, on that day or moment.
_Avoid_: event (say Event only for both kinds together), deadline (reserved for a possible future kind of Event)
